10. Interpretation caution
If PC1 explains about 30% and PC1+PC2 explains about 50%, avoid writing that 'the first two PCs explain 30%'. That value is PC1 alone. Also avoid claiming that PCA 'proves' no redundancy. A more precise phrasing is: the gradual variance decay, low number of high-correlation pairs, and meaningful loading pattern support a multidimensional feature structure.
